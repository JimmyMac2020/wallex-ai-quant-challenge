# سیستم معاملات الگوریتمی هوشمند والکس (Wallex AI Quant Engine)

موتور معاملات الگوریتمی مبتنی بر هوش مصنوعی برای **چالش والکس** روی سرمایه اولیه **۵,۰۰۰,۰۰۰ تومان**.

## ۱. معماری و منطق اصلی الگوریتم
- **لایه ۱ (تحلیلگر تکنیکال و ریزساختار دفتر سفارشات والکس):** محاسبه `EMA(9/21)`، `RSI(14)`، `ATR(14)` و استخراج عدم تعادل دفتر سفارشات (`Orderbook Bid/Ask Imbalance`) و اسپرد از `GET /v1/depth`.
- **لایه ۲ (ایجنت استراتژیست هوش مصنوعی با مدل اقتصادی `gpt-4o-mini`):** تشخیص رژیم بازار (`TRENDING_BULL`, `RANGE_SUPPORT`, `HIGH_VOL_CHOP`, `OVERBOUGHT_EXIT`) و جلوگیری از ورود در بازارهای بدون روند یا دارای اسپرد بالا.
- **لایه ۳ (نگهبان ریسک و تسویه تومانی):** محدودسازی حجم هر سفارش به حداکثر ۱۸٪ سرمایه (۹۰۰,۰۰۰ تومان)، حد ضرر پویا (`-1.2%`)، حد سود پله‌ای (`+2.4%`) و تبدیل ۱۰۰٪ دارایی‌ها به تومان (`Realized TMN`) در پایان دوره.

## ۲. نحوه استفاده از هوش مصنوعی و ابزارهای والکس
- اتصال به اندپوینت‌های رسمی والکس (`/v1/markets`, `/v1/depth`, `/v1/udf/history`, `/v1/account/orders`) و سرور `Wallex MCP`.
- استفاده از مدل کم‌هزینه `gpt-4o-mini` با سقف توکن `max_tokens: 200` و کش داخلی جهت بهینه‌سازی سرعت و هزینه.

## ۳. شرایط تصمیم‌گیری برای خرید و فروش
- **شرایط خرید (`BUY`):** قرارگیری قیمت روی حمایت `EMA21` یا `VWAP`، شاخص `RSI < 45`، برتری تقاضای خرید در دفتر سفارشات (`Imbalance > +20%`) و تأیید رژیم بازار توسط ایجنت.
- **شرایط فروش (`SELL`):** رسیدن به حد سود پله‌ای (`+2.4%`)، اشباع خرید (`RSI > 70`) یا اجرای تسویه خودکار پایان دوره به تومان (`Realized TMN`).

## ۴. روش مدیریت سرمایه و ریسک
- عدم ورود با کل سرمایه (حداکثر ۱۸٪ در هر سفارش).
- حد ضرر خودکار (`Stop-Loss = -1.2%`) و توقف معاملات روزانه در صورت افت ۲٪ کل حساب (`Circuit Breaker`).

## ۵. امکان اجرای مجدد و بررسی لاگ تصمیمات
```bash
python wallex_engine.py --mode backtest --capital 5000000 --seed 42
python wallex_engine.py --mode shadow --symbol BTCTMN
```
تمامی تصمیمات به همراه سیگنال‌ها و استدلال هوش مصنوعی در فایل `logs/decision_logs.jsonl` ذخیره می‌شوند.
