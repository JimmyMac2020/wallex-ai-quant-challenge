۱. معماری و منطق تصمیم‌گیری ۳ لایه

موتور معاملاتی والکس به جای تکیه بر شروط ساده if/else، از سه ماژول مکمل استفاده می‌کند:

  • واحد تحلیل تکنیکال و ریزساختار بازار: محاسبه EMA(9/21)، RSI(14)، ATR(14) و استخراج نسبت سفارش‌های خرید به فروش (Orderbook Imbalance) و اسپرد از اندپوینت GET /v1/depth والکس.
  • ایجنت استراتژیست هوش مصنوعی (gpt-4o-mini): داده‌های کمی را بررسی کرده، رژیم بازار را تشخیص می‌دهد و در صورت واگرایی بین اندیکاتور و عمق تابلو، از ورود پرریسک جلوگیری می‌کند.
  • نگهبان ریسک و تسویه تومانی: سقف هر سفارش را به ۱۸٪ سرمایه محدود کرده، حد ضرر پویا (1.2%) را اعمال می‌کند و در پایان دوره تمام دارایی‌های کوینی را به تومان (Realized TMN) تبدیل می‌نماید.

۲. راهنمای اجرای مجدد و اتصال به Wallex API / MCP

تمامی کدهای پایتون موتور معاملاتی، سرور Wallex MCP و فایل‌های لاگ در مخزن پروژه قرار دارند و با دستورات زیر قابل اجرا و بازتولید هستند:

# 1. Run deterministic 72h backtest & export decision logs
python wallex_engine.py --mode backtest --capital 5000000 --seed 42
# 2. Run live Shadow Testing on Wallex Orderbook
python wallex_engine.py --mode shadow --symbol BTCTMN
# 3. Run Live Trading with OpenAI gpt-4o-mini + Wallex API
WALLEX_API_KEY="..." OPENAI_API_KEY="..." python wallex_engine.py --mode live
